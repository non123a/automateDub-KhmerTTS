# Learning System

## Purpose

AutomateDub should improve after every processed media project. Learning must be explicit, permissioned, auditable, and reversible.

## Learning Sources

- accepted human corrections
- rejected AI outputs
- pronunciation fixes
- preferred translations
- preferred localized names
- character style adjustments
- voice assignment changes
- quality scores
- provider failures
- cost and latency records

## Memory Scopes

- project memory: applies only to one movie/video/audiobook
- series memory: applies across episodes/seasons
- organization memory: applies to a customer or studio
- platform memory: reusable global patterns, only when allowed by data policy

## Learning Outputs

- glossary entries
- pronunciation dictionary entries
- style guide updates
- character profile updates
- prompt evaluation notes
- provider score updates
- routing policy updates
- benchmark dataset candidates

## Controls

Learning must support:

- opt-in/opt-out by customer/project
- human approval for reusable global memory
- rollback
- audit history
- privacy and rights constraints
- deletion when source rights or consent are revoked

## Anti-Pattern

Do not silently fine-tune, cache, or reuse customer data across tenants. SaaS trust requires explicit data boundaries.

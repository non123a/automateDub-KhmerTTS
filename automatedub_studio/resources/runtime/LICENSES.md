# Bundled Runtime Notices

AutomateDub packages FFmpeg/ffprobe and Whisper.cpp binaries built or supplied
for the target platform. FFmpeg is distributed under LGPL-2.1-or-later unless
the selected build enables GPL components; Whisper.cpp is MIT licensed.

Release engineering must retain the exact upstream source/build configuration,
license notices, and any corresponding-source obligations for each released
binary. Do not ship a runtime artifact until its FFmpeg build license is
recorded in the release manifest.
